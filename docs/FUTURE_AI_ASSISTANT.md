# Future AI Assistant

Core analytics must remain deterministic and reproducible.

A future assistant may call APIs to explain results:

- `get_mt_profile`
- `get_spbu_profile`
- `get_master_data_quality`
- `get_tag_anomaly`
- `get_time_window`
- `get_spbu_pairs`
- `get_transition_profile`
- `get_route_patterns`
- `get_cluster`

The assistant should explain stored evidence and confidence. It should not calculate authoritative operational metrics itself.
